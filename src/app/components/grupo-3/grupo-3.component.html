Grupo 3: Machine Learning

Este proyecto muestra cómo un modelo puede aprender patrones a partir de ejemplos. Utilizamos un conjunto de datos de práctica para comparar predicciones, revisar errores y comprender por qué la calidad de la información influye en los resultados.

Aspectos sobresalientes del proyecto

  • Preparación y limpieza de los datos de ejemplo.
  • Separación de datos para entrenamiento y evaluación.
  • Comparación de modelos de clasificación.
  • Presentación de resultados y limitaciones del modelo.
