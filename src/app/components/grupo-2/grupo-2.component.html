Grupo 2: Desarrollo Web

Creamos una plataforma web para presentar los proyectos de nuestra feria. Combinamos diseño, programación y organización de contenidos para ofrecer una experiencia clara y accesible desde computadoras, tabletas y teléfonos.

Aspectos sobresalientes del proyecto

  • Diseño de interfaces adaptables a diferentes pantallas.
  • Organización del sitio mediante componentes y rutas.
  • Creación de formularios y navegación intuitiva.
  • Revisión de accesibilidad y experiencia de usuario.
